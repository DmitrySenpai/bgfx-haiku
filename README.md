# bgfx for Haiku OS

## 概要

このリポジトリは、オープンソースのレンダリングライブラリ **bgfx** を **Haiku OS** で動作させるために移植・修正したバージョンです。

オリジナルの bgfx をベースに、Haiku OS との互換性を向上させるための変更を加えています。

## ⚠️ 注意事項

**この移植版は現在開発・テスト段階です。**

- Haiku OS 上での動作は完全には保証されていません。
- 一部の機能が正常に動作しない可能性があります。
- 実行中にクラッシュや描画の不具合が発生する場合があります。
- 今後のアップデートで互換性と安定性を改善する予定です。

現時点では、実験的な用途や開発・テスト目的での使用を推奨します。
